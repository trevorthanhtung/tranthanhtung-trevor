# Hallmark Portfolio Design System
/* Hallmark · macrostructure: 07 Manifesto · theme: Brutal · N7 Brutal Slab · Ft4 Dense Colophon */

## Theme: Brutal
**Genre**: Editorial
**Tone**: Technical, Aggressive, Stark
**Audience**: Tech recruiters, engineering peers

### Colors (OKLCH)
- `--color-paper`: `oklch(99% 0 0)` (Pure white)
- `--color-paper-2`: `oklch(96% 0 0)` (Off white)
- `--color-paper-3`: `oklch(90% 0 0)` (Light gray)
- `--color-ink`: `oklch(10% 0 0)` (Almost black)
- `--color-ink-2`: `oklch(35% 0 0)` (Dark gray)
- `--color-ink-3`: `oklch(55% 0 0)` (Mid gray)
- `--color-accent`: `oklch(55% 0.22 25)` (Brutal Red)
- `--color-rule`: `oklch(10% 0 0)` (Thick solid black rules)

*Dark Mode* is identical but inverted: Paper becomes `oklch(10% 0 0)`, Ink becomes `oklch(99% 0 0)`, and Rule becomes `oklch(99% 0 0)`.

### Typography
- **Display (`--font-display`)**: Bricolage Grotesque (Heavy weights: 700, 800)
- **Body (`--font-body`)**: Inter (Regular)
- **Mono (`--font-mono`)**: JetBrains Mono (For data, tags, meta info)

### Space & Layout
- Rigid, heavy borders. Hairlines are replaced by 2px or 4px solid lines.
- Asymmetrical grids. Padding is structural.
- No rounded corners (all `border-radius: 0`).
- No box-shadows. Shadows are solid blocks.

### Macrostructure
07 · Manifesto. 
Large polemical type. Declaration energy.
Nav: N7 (Brutal slab). 
Footer: Ft4 (Dense Colophon).
